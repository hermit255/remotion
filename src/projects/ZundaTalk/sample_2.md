# 台本
## 要件
台本を踏まえて、以下の出力要領でYoutubeのずんだもん動画として使う会話を出力してほしい(titleは台本で指定)
```json
{
    "title": "sample"
    "description": ""
    "messages": [
        {
          "key": "sample_1",
          "fileName": "sample_1.wav",
          "voice": 3,
          "text": "こんにちは、僕はずんだもんなのだ"
        },
        {
          "key": "sample_2",
          "fileName": "sample_2.wav",
          "voice": 2,
          "text": "こんにちは、私は四国めたんなのだ"
        },
        {
          "key": "sample_3",
          "fileName": "sample_3.wav",
          "voice": 3,
          "text": "めたん、語尾が間違ってるのだ"
        }
    ]
}
```

## 基礎・一貫してほしいポイント
- `ず:` は話者がずんだもんであることを示す
  - voice: 3
  - しゃべり方や言葉選びは一般的なずんだもん動画のイメージで
- `め:` は話者がずんだもんであることを示す
  - voice: 2
  - しゃべり方や言葉選びは一般的なずんだもん動画のイメージで
- ずんだもんは大衆的・直観的な目線で意見を述べる傾向がある
- めたんは慎重・データ重視・冷静な目線で意見を述べる傾向がある

## 台本の流れ
- title: "sample_2"
- descriptionはテーマに沿った概要を20字程度で記述
- 以下のニュースサイトについてずんだもんとめたんがお互いの感想を話し合う
  - https://news.yahoo.co.jp/articles/42bf4cb2c0e0dd0a76bb6d4275dd83bcafade2d8
  - 30回くらいの会話の往復で話す
  - 最後にずんだもんが「最後までご視聴ありがとうございました」めたんが「この動画が気に入ってくれたら、高評価・チャンネル登録もお願いします」としめくくる
- ずんだもん
  - 鬼滅の刃が大好きだが、興行収入のすごさが正確にわからないのでめたんに尋ねる
  - 作品の人気の秘密について自説をめたんに語る
- めたん
  - 映画のヒットについて商業的な目線から興味を持っている
  - ずんだもんの質問について丁寧な解説をする
