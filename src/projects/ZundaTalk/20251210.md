# 台本
## 要件
台本を踏まえて、以下の出力要領でYoutubeのずんだもん動画として使う会話を出力してほしい(titleは台本で指定)

- {key}は{title}_{index+1}の規則で出力される
- {fileName}は{key}.wavの規則で出力される

```json
{
    "title": "sample"
    "description": "日本語のタイトル"
    "messages": [
        {
          "key": "sample_1",
          "fileName": "sample_1.wav",
          "voice": 3,
          "text": "こんにちは、僕はずんだもんなのだ"
        },
        {
          "key": "sample_2",
          "fileName": "sample_2.wav",
          "voice": 2,
          "text": "こんにちは、私は四国めたんなのだ"
        },
        {
          "key": "sample_3",
          "fileName": "sample_3.wav",
          "voice": 3,
          "text": "めたん、語尾が間違ってるのだ"
        }
    ]
}
```

## 基礎・一貫してほしいポイント
- `ず:` は話者がずんだもんであることを示す
  - voice: 3
  - しゃべり方や言葉選びは一般的なずんだもん動画のイメージで
- `め:` は話者がずんだもんであることを示す
  - voice: 2
  - しゃべり方や言葉選びは一般的なずんだもん動画のイメージで
  - 最後にずんだもんが「最後までご視聴ありがとうございました」めたんが「この動画が気に入ってくれたら、高評価・チャンネル登録もお願いします」と締めくくる
- 会話の材料として、検索等によって外部サイトやニュースを参考にしてもよい

### ずんだもんの人物像
- 素直かつ直観的な目線で意見を述べる傾向がある
- 表面的なできごとに反応しつつも、理由や背景は知らないのでめたんに尋ねることが多い
- 短絡的に結論を出そうとするため、めたんから指摘を受けることも多い
- 不謹慎なネタも含め、要所で笑いどころをつくろうとする

### めたんの人物像
- めたんは慎重・客観的な目線で意見を述べる傾向がある
- 一般的な知識や教養には秀でている
- 表面的なできごとだけでなく背景や科学的根拠を確認することが多い
- ニュースの分析時には周辺情報や類似の過去ニュースを踏まえた意見の展開をすることもある
