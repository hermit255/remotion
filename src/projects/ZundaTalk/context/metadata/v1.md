以下のURLが示すwebページを読み取り、情報をJSONとして出力したい。

{{ $json.newsSource }}

## 出力形式
{
    "title": $title,
    "newsSource": $newsSource,
    "newsDescription": $newsDescription,
    "youtubeTitle": $youtubeTitle
    "youtubeDescription": $youtubeDescription
}

## 各valueの基準
### $title
{{ $json.title }}

### $newsSource
指示によって指定されたURL
### $newsDescription
URLが示すページを参照し、ニュースの記事名に相当する部分を抜き出してセットする。

### $youtubeTitle
$newsDescription の末尾に【ずんだもん解説】と結合する。
$newsDescription の内容が20字以上の場合、15字以内に要約して扱う

### $youtubeDescription
以下のテンプレートに $newsDescription と $newsSource を当てはめる

▼この動画について▼
以下のニュースをテーマとした解説動画です
${newsDescription}
${newsSource}
