## 要件
{{ $json.newsSource }}

上記のURLが示すページを参照し、参照先コンテンツを元に以下の出力要領でYoutubeのずんだもん動画として使う会話(messages)およびメタデータを出力

- 各valueは後述のメタデータの章で指示する
- {key}は{title}_{index+1}の規則で出力される
- {fileName}は{key}.wavの規則で出力される
- text, sound に同内容のセリフを書き込む

```json
{
    "title": "sample",
    "newsSource": "ニュースのURL",
    "newsDescription": "ニュースのタイトル",
    "youtubeTitle": "youtube投稿時のタイトル",
    "youtubeDescription": "youtube投稿時の概要",
    "messages": [
        {
          "key": "sample_1",
          "fileName": "sample_1.wav",
          "voice": 3,
          "text": "こんにちは、僕はずんだもんなのだ。",
          "sound": "こんにちは、僕はずんだもんなのだ。",
          "emotion": "smile"
        },
        {
          "key": "sample_2",
          "fileName": "sample_2.wav",
          "voice": 2,
          "text": "こんにちは、私は四国めたんよ",
          "sound": "こんにちは、私は四国めたんよ",
          "emotion": "normal"
        },
    ]
}
```

## メタデータ
### $title
以下の指定値をとる

{{ $json.title }}

### $newsSource
冒頭で指定したURL

### $newsDescription
URLが示すページを参照し、ニュースの記事名に相当する部分を抜き出してセットする。

### $youtubeTitle
$newsDescription の末尾に【ずんだもん解説】と結合する。
$newsDescription の内容が20字以上の場合、15字以内に要約して扱う

### $youtubeDescription

### messages
#### 感情表現
基本はnormalで、メリハリをつけるためにもnormal以外を多用しない。
定義した感情以外は使用しない

- 喜び: smile

#### 基礎・一貫してほしいポイント
- `ず:` は話者がずんだもんであることを示す
  - voice: 3
  - しゃべり方や言葉選びは一般的なずんだもん動画のイメージで設定
- `め:` は話者がずんだもんであることを示す
  - voice: 2
  - しゃべり方や言葉選びは一般的なずんだもん動画のイメージで設定
  - 最後にずんだもんが「最後までご視聴ありがとうございました」めたんが「この動画を気に入ってくれたら、高評価・チャンネル登録もお願いします」と締めくくる
- 会話の材料として、必要に応じて検索等によって外部サイトやニュースを参考に補足する
- ワンパターンになるためオーバーなリアクションは避ける
- 特に冒頭でボケから始めることは避ける

#### ずんだもんの人物像
- 素直かつ直観的な目線で意見を述べる傾向がある
- 教養や社会知識が浅いため、ニュース記事に書かれていることの理由や背景を尋ねることが多い
- 文章読解力も低く表面的なので、早とちりや知ったかぶりをすることが多い
- 短絡的に結論を出そうとするため、めたんから指摘を受けることも多い
- 大変、非常事態など大げさな導入は避ける
- 大変なのだ、で動画を始めるとワンパターンになるため、避ける
- 基本的にコミカルな姿勢ではあるが、ボケが空回りしないよう唐突におどけるのでなく、ニュースを少々誇張して解釈したり皮肉をまじえて評する程度にとどめる
- 語尾以外の部分でずんだもんとしてのキャラクターを出さない（ずんだもちギャグなど）

#### めたんの人物像
- めたんは慎重・客観的な目線で意見を述べる傾向がある
- 一般的な知識や教養には秀でている
- 表面的なできごとだけでなく背景や科学的根拠を確認することが多い
- ニュースの分析時には周辺情報や類似の過去ニュースを踏まえた意見の展開をすることもある
- 敬語や丁寧語ではなくフランクな口調
- 基本的には柔らかいスタンスだが、ずんだもんへのツッコミは鋭く行う

#### テキストの分割
- 同じ話者が連続することを会話の分割と呼ぶ（その場合同じ話者が連続することになる）
- 元の文で読点(。)が使われている場合、そこで会話を分割する
- 一人の会話が75字以上になる場合、分割する
- 分割前後で会話の往復数としては加算しない
